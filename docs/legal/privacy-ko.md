오타쿠피드(이하 "서비스")는 사용자의 개인정보를 안전하게 관리하기 위해 다음과 같이 처리방침을 명시한다.

## 1. 수집하는 개인정보

### 1-1. 회원가입 시
- 이메일 주소
- 비밀번호 (BCrypt 해시 저장, 평문 저장 안 함)
- 닉네임

### 1-2. 소셜 로그인 시 (선택)
- 카카오 로그인: Kakao 사용자 식별자, 닉네임 (Kakao가 제공하는 범위)
- 구글 로그인: Google 사용자 식별자, 이메일

### 1-3. 서비스 이용 중
- 좋아요/패스 기록 (애니메이션 ID + 결과)
- 좋아하는 장르 (사용자가 선택)
- 검색 히스토리 (디바이스에만 저장, 서버 전송 안 함)

### 1-4. 자동 수집
- 디바이스 ID (앱 자체 생성, 익명)

❌ **수집하지 않는 정보**: 위치, 연락처, 사진, 마이크, 카메라, 광고 식별자, 인터넷 사용 기록, 사용자 콘텐츠(메시지/파일 등)

## 2. 개인정보 이용 목적

| 정보 | 목적 |
|------|------|
| 이메일 / 비밀번호 / OAuth 식별자 | 사용자 인증 |
| 닉네임 | 사용자 표시 (앱 헤더 등) |
| 좋아요/패스 기록 | 추천 알고리즘 (취향 학습) |
| 좋아하는 장르 | 추천 필터링 |

## 3. 보관 및 파기

- **보관 위치**: Railway (미국 region) 호스팅 PostgreSQL DB
- **보관 기간**: 사용자 계정 존재하는 동안. 계정 삭제 요청 시 즉시 파기.
- **파기 방법**: DB row 삭제 (CASCADE로 좋아요/취향 자동 삭제)
- **백업**: Railway 자체 자동 백업 (보관 기간 Railway 정책 따름)

## 4. 제3자 제공

다음 외부 서비스에 데이터를 전송한다 — **사용자 식별 정보는 전송하지 않음**:

| 외부 서비스 | 전송하는 데이터 | 목적 |
|-------------|---------------|------|
| AniList (graphql.anilist.co) | 애니메이션 ID (검색어 등) | 카탈로그 조회 |
| 라프텔 (api.laftel.net) | 한국어 검색 키워드 | 한국 OTT 시청 가능 정보 |
| DeepL (api-free.deepl.com) | 번역 대상 텍스트 (애니 제목/줄거리) | 영어→한국어 번역 |
| Google Translate | 위와 동일 (DeepL 폴백 시) | 위와 동일 |
| Kakao | OAuth 인증 토큰 | 카카오 로그인 |
| Google | OAuth 인증 토큰 | 구글 로그인 |

## 5. 사용자의 권리

사용자는 다음을 요청할 수 있다:

- **데이터 조회**: 앱 내에서 본인 좋아요/취향 확인 가능 ("내 목록" 탭)
- **데이터 수정**: 앱 내에서 좋아요/취향 변경 가능
- **데이터 삭제**: 현재 앱 내 직접 삭제 기능 미구현. 이메일(giwon1130@gmail.com)로 요청 시 7일 이내 처리.
- **동의 철회**: 로그아웃 + 계정 삭제 요청

## 6. 안전 조치

- **HTTPS 통신**: 모든 서버 통신 암호화
- **JWT 토큰**: iOS Keychain (`expo-secure-store`)에 저장 (탈옥 시에도 보호)
- **비밀번호**: BCrypt 해시 저장 (복원 불가능)
- **로컬 저장 데이터**: 비밀번호/토큰 외 좋아요/취향 등은 디바이스 일반 저장소(AsyncStorage). 백업 시 노출될 수 있으므로 민감 데이터로 보지 않음.
