# 📚 Otaku Feed 문서

이 폴더는 **사람용** 문서야. 자동화 에이전트(Claude 등) 용 노트는 저장소 루트의
[`AGENTS.md`](../AGENTS.md) 에 있어.

**프로젝트 한 줄**: 한국 사용자를 위한 애니 추천 피드 앱. 스와이프로 학습한 취향에 맞춰
AniList 카탈로그 + 라프텔 시청 가능 정보를 보여준다.

**클라이언트 기술 스택**: React Native 0.81 / Expo 54 / TypeScript / iOS·Android.
**백엔드 (별도 레포)**: [otaku-feed-api](https://github.com/giwon1130/otaku-feed-api) — Spring Boot + Kotlin / PostgreSQL / Railway 배포.

## 문서 작성 원칙

1. **첫 줄에 "누가 봄 / 언제 봄"** 명시
2. **모든 결정에 "왜"** — 코드는 "무엇"만 알려줌
3. **링크 우선, 복붙 금지** — 정의는 한 곳
4. **반말체 + 한국어** (제품 톤)
5. **AGENTS.md와 분리** — 자동화용은 별도
