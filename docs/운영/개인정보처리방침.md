## 위치

- **원본 markdown**: `docs/legal/privacy-ko.md`, `docs/legal/privacy-en.md`
- **공개 URL** (GitHub Pages 활성화 후): `https://giwon1130.github.io/otaku-feed/legal/privacy-ko`

App Store 제출 시 URL은 **한국어 버전**:
```
https://giwon1130.github.io/otaku-feed/legal/privacy-ko
```

## GitHub Pages 활성화 (한 번만)

1. GitHub 저장소 → **Settings** → **Pages**
2. **Source**: Deploy from a branch
3. **Branch**: `main` / Folder: `/docs`
4. Save → 1-2분 후 활성화

활성화 확인:
```bash
curl -I https://giwon1130.github.io/otaku-feed/legal/privacy-ko
# 200 응답이면 OK (404면 아직 deploy 진행 중)
```

GitHub Pages는 markdown을 자동으로 HTML 변환 (Jekyll). 별도 빌드 도구 X.

## 변경 흐름

1. `docs/legal/privacy-ko.md` 또는 `privacy-en.md` 수정
2. **`최종 수정일`** 갱신
3. 중대한 변경이면 (수집 항목 추가/제3자 변경 등) **30일 전 공지** — 앱 toast 또는 메뉴에 링크
4. git push → GitHub Pages 자동 배포 (1분 내)
5. App Store Connect의 처리방침 URL은 같으니 변경 불필요

## App Store Connect 등록

App Store Connect → 우리 앱 → **App Privacy** → "Privacy Policy URL"에 위 URL 입력.

심사 시 Apple이 직접 접속해서 확인하므로 GitHub Pages가 down되면 안 됨.

## 변경 이력 추적

처리방침 변경 시 git diff가 그대로 변경 이력. 별도 changelog 파일 안 만듦.

이전 버전 보기: `https://github.com/giwon1130/otaku-feed/commits/main/docs/legal/privacy-ko.md`

## 주의

- 코드에 새 데이터 수집 추가 시 **반드시 처리방침 갱신**
  - 예: 위치 권한 도입 → "수집하는 정보"에 위치 추가
  - 예: 새 외부 서비스 연동 → "제3자 제공" 표 추가
- App Store Connect의 **App Privacy 답변**도 동시 갱신 (questionnaire 형식)

## 카카오/구글 동의 화면

OAuth 로그인 시 사용자에게 보이는 동의 화면은 **Kakao / Google이 자체 처리** — 우리 처리방침과 별개로 그쪽이 동의 받음.

단, 우리가 **그 데이터를 어떻게 쓰는지**는 우리 처리방침에 명시 (이미 4번 항목에 있음).

## 안 한 것 (검토)

- ❌ **별도 동의 화면 (앱 내)** — 회원가입 자체가 동의로 간주
  - GDPR 엄격 적용 시 명시적 체크박스 필요. 한국 사용자 위주라 현재 미적용
- ❌ **개인정보 보호법 위탁 처리 표시** — 외부 서비스(Railway/AniList 등) 모두 "수탁자"로 명시 필요할 수도. 사용자 수 늘면 검토
- ❌ **만 14세 미만 부모 동의** — 14세 이상만 가입 받는 정책으로 회피
