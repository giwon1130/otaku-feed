# 환경변수

> **누가 봄**: DevOps, FE (로컬 셋업)
> **언제 봄**: 첫 셋업, 새 키 추가, 키 회전
> **단일 진실의 원천**: `.env.example` (커밋됨), 이 문서 (의도/획득 방법)

## 클라이언트 (`.env`)

`/Volumes/Dev/Playground/otaku-feed/.env` — gitignore됨. 로컬에서 `.env.example` 복사해서 채움.

| 키 | 용도 | 필수 | 획득 |
|----|-----|-----|------|
| `EXPO_PUBLIC_API_URL` | otaku-feed-api 베이스 URL | ✅ | 로컬: `http://localhost:8092`, 프로덕션: `https://otaku-feed-api-production.up.railway.app` |
| `EXPO_PUBLIC_DEEPL_API_KEY` | DeepL 번역 API 키 | ⚠️ | DeepL 가입 → API Free 키. 없으면 Google 번역으로 폴백 |
| `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` | Google SSO web client | ✅ (SSO 쓰면) | Google Cloud Console → APIs & Services → Credentials |
| `EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID` | Google SSO iOS client | ✅ (iOS) | 위 콘솔 → iOS 앱 추가 |
| `EXPO_PUBLIC_KAKAO_APP_KEY` | Kakao SSO | ✅ (Kakao 쓰면) | Kakao Developers → 앱 → 네이티브 앱 키 |

`EXPO_PUBLIC_` 접두어가 있어야 `process.env`로 런타임 접근 가능. 클라이언트 번들에 포함되니 **공개돼도 되는 키만**.

## 백엔드 (Railway 환경변수)

자세한 목록: [백엔드 docs/운영/환경변수.md](https://github.com/giwon1130/otaku-feed-api/blob/main/docs/운영/환경변수.md)

요약:
- `PORT` — Railway 자동 주입
- `PGHOST`/`PGPORT`/`PGDATABASE`/`PGUSER`/`PGPASSWORD` — PostgreSQL 자동 주입
- `JWT_SECRET` — 32+ chars 랜덤 (수동)
- `OTAKU_CORS_ALLOWED_ORIGINS` — 기본 `*` (모바일 앱이라 origin 의미 없음)

## 키 회전

### DeepL
1. 새 키 발급
2. `.env` 업데이트
3. 풀빌드 (env는 빌드 시점 주입)
4. 옛 키 비활성화

### JWT_SECRET
⚠️ 회전하면 **모든 사용자 즉시 로그아웃** (기존 토큰 invalid).
- 사용자 영향 최소화: 평일 새벽 또는 점검 공지 후
- Railway에서 환경변수 변경 → 자동 재배포
- 모바일 앱은 401 받으면 토큰 정리 + 재로그인 유도 (TODO: 자동화)

### Google/Kakao Client ID
⚠️ 클라이언트 ID는 보통 회전 안 함 (앱 식별자). secret은 백엔드에만.

## 새 환경변수 추가 절차

1. `.env.example`에 키 추가 (값 X, 설명 주석)
2. 이 문서에 추가 (용도/획득 방법)
3. 코드에서 `process.env.EXPO_PUBLIC_X` 사용 (클라) 또는 `${X:default}` (백엔드 yml)
4. AGENTS.md에도 짧게
5. (백엔드면) Railway 대시보드에 값 설정

## 보안 주의

- `.env`는 절대 commit 금지 (.gitignore 확인)
- API 키는 GitHub secret scan에 걸리니 leak 시 즉시 회전
- `EXPO_PUBLIC_*`는 클라 번들에 들어감 → secret이 아닌 것만 (DeepL Free 키는 공개돼도 큰 피해 없음, 사용량 한도라)
