## 알려진 증상 → 원인 → 대응

### "오타쿠피드를 더이상 사용할 수 없음"
- **원인**: 7일 무료 provisioning profile 만료
- **대응**: 풀빌드 재설치 (운영/배포.md 참고)
- **예방**: EAS 빌드 도입 (1년 유효)

### 앱이 부팅 시 "[runtime not ready]: Cannot find native module 'X'"
- **원인**: 새 native 모듈을 import했는데 풀빌드 안 함
- **대응**:
  1. 즉시: 그 import를 코드에서 제거 + push (사용자 unblock)
  2. 추후: 풀빌드 후 다시 추가
- **예방**: `package.json` deps 변경 후 항상 `git diff --name-only` 확인 → 풀빌드 필요 판정

### Railway 응답 5–10초 느림
- **원인**: Hobby plan idle 5분 후 sleep → 첫 호출 cold start
- **대응**: 자연 (한 번 깨면 빠름)
- **예방**: `apiHealth` keepalive (이미 있음, 로그인 시만)

### "AniList 요청이 너무 잦아" 토스트
- **원인**: 90 req/min/IP 한도 초과
- **대응**: 30초 정도 기다렸다 재시도
- **예방**: 클라이언트 동시성 큐 (이미 5개 제한). 더 빡빡하게 하려면 max 3으로

### MyListTab의 anime 카드가 모두 skeleton
- **원인**: `fetchAnimeById`가 다 실패 (네트워크/AniList 다운)
- **대응**: 새로고침 (pull-to-refresh) 한번 더
- **진단**: Metro 콘솔에서 `[exception]` 로그 확인

### 기존 사용자 좋아요 목록이 안 보임
- **원인**: 다른 디바이스 로그인 시 `loadSwipes`가 5분 TTL 안에 옛 캐시 반환
- **대응**:
  - 사용자: pull-to-refresh
  - 코드: `KEYS.syncMeta`에서 `swipesAt` 제거하면 강제 fresh

### 잘못된 한국어 번역 ("장례식의 프리렌" 같이)
- **원인**: 옛 번역 캐시(`tl3:`) 잔존
- **대응**: 이미 `tl4:`로 prefix bump됨 (자동 무효화)
- **진단**: AsyncStorage 키 prefix 확인

### 백엔드 가짜 JWT에 500 응답
- **원인**: JwtProvider 파싱 예외 unhandled
- **대응**: 백엔드 fix됨 (ResponseStatusException(401))
- 재발 시: `JwtProvider.extractUserId` 확인

## 대응 우선순위

| 영향 범위 | 대응 시간 |
|----------|----------|
| 모든 사용자 부팅 불가 (앱 크래시) | 즉시 — JS revert + 빌드 |
| 핵심 기능 (스와이프/홈) 동작 안 함 | 1시간 내 |
| 일부 기능 또는 일부 사용자 | 1일 내 |
| 비용 급증 알림 | 그날 안에 점검 |
