# App Store 제출

> **누가 봄**: DevOps, PM
> **언제 봄**: 첫 제출, release update
> **함께 봐야 할 문서**: [`테스트플라이트.md`](테스트플라이트.md), [`개인정보처리방침.md`](개인정보처리방침.md), [`배포.md`](배포.md)

## 전체 흐름

```
1. App Store Connect 앱 등록 (한 번만)
2. Metadata 입력 (한 번 + 업데이트마다 일부)
3. 스크린샷 캡처 + 업로드
4. App Privacy 답변 (한 번만)
5. 빌드 업로드 (eas submit)
6. 빌드 선택 + Submit for Review
7. 심사 대기 (1-3일)
8. Approve → 릴리즈
```

## 1. App Store Connect 앱 등록 (한 번만)

이미 [`테스트플라이트.md`](테스트플라이트.md)에서 등록했으면 스킵.

## 2. Metadata 체크리스트

App Store Connect → 우리 앱 → **App Information** + **iOS App / 1.0 Prepare for Submission**.

### 필수
| 필드 | 값/예시 | 비고 |
|------|---------|------|
| Subtitle (30자) | 한국 OTT까지 알려주는 애니 추천 | App Name 옆 작은 글씨 |
| Promotional Text (170자) | 자주 변경 가능 (심사 없이) | 시즌 변경 시 활용 |
| Description (4000자) | 아래 템플릿 | 줄바꿈 자유, 마크다운 X |
| Keywords (100자) | `애니,애니메이션,추천,라프텔,넷플릭스,오타쿠,취향,장르,일본` | 콤마 구분, 띄어쓰기 X |
| Support URL | `https://github.com/giwon1130/otaku-feed/issues` 또는 별도 사이트 | 사용자 문의 채널 |
| Marketing URL | (선택) 비워도 OK | |
| Category Primary | Entertainment | |
| Category Secondary | Lifestyle (선택) | |
| Privacy Policy URL | `https://giwon1130.github.io/otaku-feed/legal/privacy-ko` | [개인정보처리방침.md](개인정보처리방침.md) 참고 |
| Copyright | `2026 임기원` | 단순 형식 |
| Sign-In Information | 심사용 테스트 계정 | 회원가입/로그인 있으면 필수 |

### Description 템플릿 (한국어)

```
🎌 한국에서 어떤 OTT에서 봐야 하는지까지 알려주는 애니 추천 앱.

📺 핵심 기능
• 좋아요/패스 스와이프로 취향 학습
• 라프텔/넷플릭스/디즈니+ 등 한국 시청 가능 플랫폼 자동 표시
• 시리즈 보는 순서 (Prequel/Sequel/외전) 정렬
• AniList synonyms에서 한국 공식 출시명 우선 (예: 장송의 프리렌)

🎯 누구를 위해
영어 제목·줄거리가 부담스럽고, 어디서 볼 수 있는지 매번 검색하기 귀찮은 분.

🔓 비로그인도 모든 기능 동작
로그인하면 디바이스 간 좋아요/취향 동기화.

데이터 출처: AniList (글로벌 카탈로그) + 라프텔 (한국 OTT 정보)
```

### Sign-In Information (심사용)

심사관은 우리 앱을 직접 사용해본다. 회원가입/로그인 막혀있으면 즉시 거절.

```
Email: review@otakufeed.example
Password: ReviewTest2026!
Notes:
- 비로그인 모드도 모든 핵심 기능 사용 가능 (오른쪽 상단 "스킵")
- 카카오/구글 SSO도 동작하지만 위 이메일/비밀번호 사용 권장
- 첫 화면 온보딩 (장르 선택 → 취향 분석)을 통과해야 메인 진입
```

→ 위 계정을 백엔드에 미리 만들어 두기.

## 3. 스크린샷

### 요구 사이즈
iOS 17+ 기준:

| 크기 | 디바이스 | 필수 여부 |
|------|---------|----------|
| **6.9" (1290×2796)** | iPhone 17 Pro Max | ✅ 필수 |
| 6.7" (1290×2796) | iPhone 14 Pro Max | (6.9가 cover하면 자동) |
| 6.5" (1284×2778) | iPhone 11 Pro Max | (6.9가 cover) |
| 6.1" (1179×2556) | iPhone 17 | (6.9가 cover) |
| 5.5" (1242×2208) | iPhone 8 Plus | 안 만들어도 OK |

✅ **iPhone 17 Pro Max 1세트만 만들면 모든 iPhone 크기 cover 됨**.

### 개수
- 최소 1장, 최대 10장
- 추천 5-6장 (핵심 화면)

### 캡처 방법
1. 폰에서 빌드 실행 → 핵심 화면 진입
2. 사이드 버튼 + 볼륨 위 동시 누름
3. AirDrop으로 Mac 전송
4. 또는 Xcode → Window → Devices and Simulators → 폰 선택 → "Take Screenshot"

### 제안 화면 (5장)
1. **홈 탭** — "오늘의 픽" + "이거 좋아하니까" 캐러셀
2. **스와이프 탭** — 카드 한 장 + 좋아요/패스 버튼
3. **디테일 모달** — "어디서 봐?" 라프텔/Netflix 표시
4. **시리즈 보는 순서** — Prequel/Sequel 그룹 정렬
5. **내 목록 + 인사이트** — top 장르/스튜디오/평균 점수

### 텍스트 오버레이 (선택)
스크린샷 위에 큰 카피("취향대로 발견해" 등) 추가 가능 — Figma/Canva 사용. 심사 외에 큰 효과 없음, 시간 들이지 말 것.

## 4. App Privacy 답변

App Store Connect → 우리 앱 → **App Privacy**. 한 번만 답변하면 됨.

| 질문 | 답변 |
|------|------|
| Do you or your third-party partners collect data? | **Yes** |
| Contact Info → Email Address | ✅ Linked to identity / App Functionality |
| Contact Info → Name | ✅ Linked to identity / App Functionality (nickname) |
| User Content → Other User Content | ✅ Linked to identity / App Functionality (좋아요/패스) |
| Identifiers → User ID | ✅ Linked to identity / App Functionality (UUID) |
| Identifiers → Device ID | ✅ NOT linked to identity / App Functionality |
| Tracking | **No** (광고 트래킹 없음) |

다른 항목 (Location/Photos/Health 등)은 모두 **No**.

## 5. Age Rating

App Store Connect → **Age Rating** 질문지:

| 질문 | 답변 |
|------|------|
| Cartoon or Fantasy Violence | None (애니 카탈로그는 메타만) |
| Realistic Violence | None |
| Sexual Content / Nudity | None |
| Profanity | None |
| Mature/Suggestive Themes | None (단, 일부 애니가 성인용일 수 있어 검토 필요) |
| Horror/Fear | None |
| Medical/Treatment | None |
| Gambling | None |
| Unrestricted Web Access | **Yes** (외부 OTT 링크 — 라프텔/Netflix 등) |
| Access to Information about Restricted Web Sites | No |

**예상 등급**: **9+** 또는 **12+** (외부 링크 포함). 보수적으로 12+로 답해도 무방.

## 6. Encryption Export Compliance

이미 `app.json`에 `ITSAppUsesNonExemptEncryption: false` 설정됨. App Store Connect에서도 동일하게 답변 — 업로드마다 묻지 않게 됨.

## 7. 빌드 업로드 + Submit

```bash
cd /Volumes/Dev/Playground/otaku-feed

# 1. App Store용 빌드 (autoIncrement buildNumber)
npm run build:prod
# 또는: npx eas build --platform ios --profile production

# 2. App Store Connect에 업로드
npm run submit:prod
# 또는: npx eas submit --platform ios --profile production --latest
```

업로드 후 App Store Connect → 우리 앱 → **TestFlight** 탭에서 빌드 표시 (Processing → Ready).

→ **iOS App / 1.0 Prepare for Submission** → "Build" 섹션에서 방금 업로드한 빌드 선택.

→ 우측 상단 **Submit for Review** 클릭.

## 8. 심사 기간

- 평균 **24-48시간**
- 첫 제출은 보통 더 오래 (~3일)
- 거절되면 사유 + 다음 작업 안내 옴 → fix 후 재제출 (재심사 다시 24-48h)

상태 확인:
- App Store Connect → 우리 앱 → 좌측 "Activity" → 심사 단계 표시
  - Waiting for Review → In Review → Pending Developer Release / Ready for Sale

## 9. 자주 거절되는 이유

| 이유 | 대응 |
|------|------|
| **2.1 App Completeness** — 크래시 / 빈 화면 | TestFlight로 충분히 검증 후 제출 |
| **2.3.7 Accurate Metadata** — Description 과장 | 실제 기능과 일치 |
| **3.1.1 In-App Purchase** — 외부 결제 안내 | 우리는 무료라 해당 X |
| **4.0 Design** — 너무 단순 / "it's just a website" | RN 네이티브라 OK, 기능 명확 |
| **5.1.1 Privacy** — 처리방침 미연결 / App Privacy 답변 누락 | 위 4번 + URL 등록 |
| **5.1.2 Data Use and Sharing** — 데이터 수집 사유 불충분 | 처리방침에 명확히 |
| **2.5.1 Software Requirements** — Private API 사용 | RN/Expo가 알아서 처리 |
| **2.5.2 Modifying iOS or jailbreak detection** | 해당 없음 |
| **4.5 SiriKit / etc** — 미사용 framework | 해당 없음 |
| **5.6 Beta Testing** — 안내 미흡 | TestFlight Notes 채우기 |

## 10. 업데이트 (1.0.1, 1.1.0 등)

```bash
# 1. app.json version bump (예: 1.0.0 → 1.0.1)
# 2. 빌드 (autoIncrement buildNumber)
npm run build:prod

# 3. 업로드 + 새 버전으로 App Store Connect에서 "Add Version"
npm run submit:prod
```

App Store Connect → "+ Version" → 1.0.1 → 위 metadata 일부 갱신 → Submit.

**Promotional Text는 심사 없이 변경 가능** — 시즌 변경 시 활용.

## 11. 첫 제출 체크리스트

- [ ] Apple Developer Program 가입됨 (✅ 완료)
- [ ] App Store Connect에 앱 등록 (Bundle ID 매칭)
- [ ] EAS Build 셋업 (`eas init` + `eas credentials`)
- [ ] 처리방침 URL 살아있음 (`curl -I` 200 OK)
- [ ] App Privacy 답변 완료
- [ ] Age Rating 답변 완료
- [ ] Description / Keywords / Subtitle 작성
- [ ] Screenshots 5장 이상 (iPhone 6.9")
- [ ] Sign-In Information 작성 + 백엔드에 심사용 계정 미리 생성
- [ ] Production 빌드 업로드 (`npm run build:prod && npm run submit:prod`)
- [ ] App Store Connect에서 빌드 선택
- [ ] TestFlight로 본인이 직접 1번 검증
- [ ] **Submit for Review** 클릭
