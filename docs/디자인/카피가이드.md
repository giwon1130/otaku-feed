# 카피 가이드

> **누가 봄**: Designer, FE (UI 카피 추가/수정 시), PM
> **언제 봄**: 새 화면 텍스트 정할 때, 에러 메시지 추가할 때
> **함께 봐야 할 문서**: [`../제품/용어집.md`](../제품/용어집.md)

## 톤

**친근한 반말.** "너"라고 부름. 격식 없음. 너무 캐주얼하지도 않음 (이모지 남발 X).

### 좋은 예
- "아직 좋아요한 애니가 없어.\n스와이프 탭에서 하트를 눌러봐!"
- "너 좋아할 만한 거"
- "어디서 볼 수 있어?"
- "랭킹을 불러오지 못했어"

### 안 좋은 예
- ❌ "좋아요한 작품이 없습니다." (격식체)
- ❌ "당신의 취향" (당신 X)
- ❌ "🎉🎉🎉 완료!! 🚀🚀" (이모지 남발)
- ❌ "Failed to load." (영어)

## 길이

- **버튼**: 2–6자 ("로그인", "다시 분석", "전체 삭제")
- **섹션 제목**: 4–10자 ("오늘의 픽", "이거 좋아하니까")
- **빈 상태 메시지**: 1–2 문장
- **에러 토스트**: 한 문장 (사용자가 뭘 해야 하는지 함의)

## 에러 메시지 패턴

`src/i18n/strings.ts`에 모음. 새 에러는 거기에 추가.

```ts
errors: {
  network:        '네트워크 연결을 확인해줘',
  rateLimit:      'AniList 요청이 너무 잦아. 잠시 후 다시 시도해줘',
  serverDown:     'AniList 서버에 문제가 있어. 잠시 후 다시 시도해줘',
  rankingFailed:  '랭킹을 불러오지 못했어',
  searchFailed:   '검색 실패',
  feedFailed:     '피드를 불러오지 못했어',
}
```

**원칙**: 사용자가 다음 행동을 알 수 있게.

| 좋음 | 나쁨 |
|-----|-----|
| 네트워크 연결을 확인해줘 | 네트워크 오류 |
| 잠시 후 다시 시도해줘 | 503 Service Unavailable |
| 랭킹을 불러오지 못했어 (자동 재시도 안 됐다는 함의) | 알 수 없는 오류가 발생했습니다 |

## 이모지 사용

UI 라벨엔 ❌. 다음에서만 OK:

- 빈 상태 일러스트 대용: 💜, 👻, 🔍
- 카피 강조: 🎌 (애니 관련), 🔥 (트렌딩), 💜 (좋아요)
- 정렬 라벨 보조: "🔥 트렌딩", "⭐ 점수순", "👥 인기순"

## 한국어 표기

- **외래어**: 표준 표기 ("애니메이션" → 보통 "애니"로 줄임)
- **숫자**: 아라비아 숫자 ("12화", "2023년")
- **시즌**: "봄/여름/가을/겨울" 또는 "Spring/Fall" — UI에선 한국어
- **장르**: `GENRE_KO` 매핑 (예: "Romance" → "로맨스")
- **년도**: "2023년" 또는 "2023" (둘 다 OK)

## 시간 표현

- **오늘** / **어제**
- **N분 전** / **N시간 전** / **N일 전**
- 일주일 넘으면 절대 날짜 ("4월 18일")

## 정중함 vs 친근함

기본은 친근함. 단, 다음은 정중하게:

- **결제 관련** (현재 없음, 미래 대비)
- **삭제 확인** ("정말 삭제할까?" — 친근하지만 신중)
- **법적 동의** (개인정보 처리방침 등)

## 버튼 문구 패턴

| 액션 | 문구 |
|------|------|
| 긍정 진행 | "다음", "완료", "확인" |
| 부정/취소 | "닫기", "취소", "전체 삭제" |
| 재시도 | "다시 시도" |
| 변경 | "다시 고르기", "다시 분석" |
| 외부 이동 | "라프텔에서 보기" |

## 아직 정리 안 된 것

- 회원가입/로그인 화면 카피 (현재 일관성 점검 필요)
- 비로그인 → 로그인 권유 시점/문구
