# 컴포넌트

> **누가 봄**: Designer, FE
> **언제 봄**: 새 화면 만들 때 ("이거 이미 있나?"), 컴포넌트 검수
> **단일 진실의 원천**: `src/components/` (구현), 이 문서 (인벤토리)

## 공용 (`src/components/shared/`)

배럴 export(`shared/index.ts`)로 일괄 import.

| 컴포넌트 | 용도 | Props 핵심 |
|---------|-----|------------|
| `ScoreBadge` | 별 + 점수 | `score: number, size?: 'sm'\|'md'\|'lg'` — score 0이면 렌더 안 함 |
| `GenreTag` | 장르 칩 | `genre: string, variant?: 'solid'\|'soft', size?` — `GENRE_KO`로 한국어 변환 |
| `MetaRow` | Anime 한 줄 메타 | `anime: Anime` — score/episodes/year+season/studio/status |
| `RelationBadge` | 시리즈 관계 배지 | `relation: RelationType` — SEQUEL/PREQUEL 등 |
| `AnimeCard` | 표준 카드 (130×185) | `anime, swipeResult?, onPress` — 좋아요/패스 배지 |
| `AnimeMiniCard` | 작은 카드 (110×156) | 비슷한 작품 캐러셀용 |

## 디테일 모달 섹션 (`src/components/detail/`)

`AnimeDetailModal`은 오케스트레이터 역할만 (state + 섹션 조립). 각 섹션은 prop만 받음.

| 컴포넌트 | 용도 |
|---------|-----|
| `DetailHeader` | 배너 이미지 + 닫기 버튼 + 커버 썸네일 |
| `WhereToWatch` | 한국 시청 가능 플랫폼 (라프텔 우선) |
| `Synopsis` | 줄거리 (번역/HTML strip 포함) |
| `SeriesOrder` | 시리즈 보는 순서 (그룹 디바이더 + RelationBadge) |
| `SimilarList` | 비슷한 작품 캐러셀 (`AnimeMiniCard`) |

## 보조 (`src/components/`)

| 컴포넌트 | 용도 |
|---------|-----|
| `AnimeDetailModal` | 디테일 모달 (위 5개 섹션 조립) |
| `LoadingBar` | 얇은 indeterminate progress (모달 상단) |
| `Toast` | 화면 하단 알림 (`useToast` 훅과 짝) |
| `Skeleton` | 로딩 placeholder (네모 + 둥근 모서리) |
| `ImageWithLoader` | 이미지 + skeleton 페이드인 |
| `OnboardingScreen` | 장르 선택 (mode='create'\|'edit') |
| `TasteOnboardingScreen` | 취향 분석 카드 (mode 동일) |
| `AuthScreen` | 로그인/회원가입 |

## 패턴

### 카드 컴포지션
```tsx
<AnimeCard anime={a} swipeResult={swipeMap[a.id]} onPress={onAnimePress} />
```
좋아요/패스 배지가 `swipeResult`로 자동 추가됨. 카드 자체에 햅틱은 부모에서.

### 섹션 헤더
```tsx
<View style={styles.cardTitleRow}>
  <SomeIcon size={14} color={C.accent} strokeWidth={2.5} />
  <Text style={styles.cardTitle}>섹션 제목</Text>
</View>
```

### 빈 상태
```tsx
<View style={styles.emptyState}>
  <Text style={{ fontSize: 40 }}>🔍</Text>
  <Text style={styles.emptyStateText}>"...에 해당하는 애니가 없어."</Text>
</View>
```

### 로딩
- 작은 영역: `<ActivityIndicator color={C.accent} />`
- 화면 전체: `<SkeletonHome />` / `<SkeletonRows />` / `<SkeletonList />`
- 디테일 모달: `<LoadingBar visible={anyLoading} />` (상단 indeterminate)

## 신규 컴포넌트 추가 가이드

1. `src/components/shared/`에 만든다 (재사용 가능하면)
2. `shared/index.ts` 배럴에 추가
3. 디자인 토큰(`C_TOKENS`) 사용 — hardcoded 색 X
4. `__DEV__` Console.log 제거 (production 빌드)
5. 같은 인라인 JSX가 2곳 이상 있으면 shared로 올린다
