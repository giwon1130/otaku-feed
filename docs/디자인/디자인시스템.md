# 디자인 시스템

> **누가 봄**: Designer, FE
> **언제 봄**: 새 화면/컴포넌트 만들 때, 색·간격 정할 때
> **단일 진실의 원천**: `src/styles.ts`의 `C_TOKENS` (런타임), 이 문서 (의도)

## 색상 팔레트

### 강조색 (보라 계열)
- `#9f67ff` — 1차 강조 (활성 탭, 강조 아이콘, 점수 별)
- `#7c3aed` — 2차 강조 (필터 칩 active 배경)
- `#2d1b69` — 강조 배경 (좋아요 배지 등)
- `accentSoft` (`rgba(159,103,255,0.18)`) — 옅은 강조 배경

### 배경
- `#0f0f1a` — 앱 전체 배경
- `#1a1a2e` — 카드/섹션 배경
- `#2a2a4a` — 보더, 구분선

### 텍스트
- `#f0f0ff` (`ink`) — 1차 텍스트 (제목)
- `#a8a8cc` (`inkSub`) — 2차 텍스트 (메타)
- `#6b6b99` (`inkMuted`) — 3차 텍스트 (보조 정보)
- `#45456b` (`inkFaint`) — placeholder, 비활성

### 상태
- `#f59e0b` — 별/점수 (gold)
- `#ef4444` — 패스, 에러
- `#06b6d4` — 정렬 인디케이터 (cyan)

### 디자인 토큰 위치
`src/styles.ts`의 `export const C_TOKENS`. 새 색을 추가하면 여기 먼저 정의 후 사용.

## 간격 (4의 배수)

- 4 — 아이콘과 짝꿍 텍스트 사이
- 6 — 칩 내부, 작은 gap
- 8 — 일반 gap, 기본 padding
- 10 — 카드 내부 padding
- 12 — 큰 gap, 카드 vertical
- 14 — 화면 horizontal padding
- 16 — 대형 padding
- 20 — 모달 horizontal

## 타이포

| 용도 | 크기 | 굵기 |
|------|-----|------|
| 모달 제목 | 22 | 900 |
| 카드 제목 | 18 | 800 |
| 카드 부제 | 14 | 600 |
| 메타/라벨 | 12 | 700 |
| 작은 메타 | 11 | 700 |
| 가장 작은 | 10 | 800 |

폰트는 시스템 기본 (San Francisco / Roboto). 커스텀 폰트 안 씀.

## 모서리 (`borderRadius`)

- 4 — 인라인 스코어 배지
- 8 — 작은 카드/버튼
- 10 — 일반 카드 내부 요소
- 12 — 검색창
- 14 — 큰 카드, 모달 내부
- 999 — 칩, pill

## 그림자

```ts
// 강조 카드 (오늘의 픽 등)
{
  shadowColor: '#9f67ff',
  shadowOffset: { width: 0, height: 6 },
  shadowOpacity: 0.25,
  shadowRadius: 12,
  elevation: 6,
}
```

일반 카드는 그림자 안 씀 (다크 테마라 보더로 분리).

## 다크 모드

**다크 only.** Light 모드 미지원 (의도적 — 애니/영상 콘텐츠는 어두운 배경이 시각적으로 잘 어울림).

## 햅틱

| 트리거 | 강도 |
|--------|------|
| 탭/네비게이션 | `hapticLight` |
| 의미 있는 액션 (정렬 변경 등) | `hapticMedium` |
| 삭제/패스 | `hapticError` |

`src/utils/haptics.ts`. 모든 버튼은 무조건 light 이상.

## 안 쓰기로 한 것

- ❌ 그라디언트 — 헤더 외엔 안 씀 (다크 톤에서 노이즈)
- ❌ 화이트 배경 카드 — 다크 일관성
- ❌ 둥근 모서리 32+ — 너무 캐주얼
- ❌ 이모지 — UI 외 (카피에선 OK: "💜", "🔥", "🎌")
