# 요구사항 (PRD)

> **누가 봄**: PM, FE, BE, QA
> **언제 봄**: 새 기능 구현 직전, 인수 테스트 작성할 때
> **함께 봐야 할 문서**: [`사용자흐름.md`](사용자흐름.md), [`용어집.md`](용어집.md)

## 우선순위 표기

- 🔴 P0 — 핵심 기능, 빠지면 앱 의미 없음
- 🟡 P1 — 중요 기능, 1차 출시 포함
- 🟢 P2 — 있으면 좋음, 차후

---

## 🔴 P0 — 핵심

### F1. 온보딩
- F1-1. 첫 부팅 시 좋아하는 장르 다중 선택 (`onboardingDone`)
- F1-2. 장르 기반 추천 카드 10개를 좋아요/패스로 분류 (`tasteOnboardingDone`)
- F1-3. 두 단계 완료 후 메인 진입
- F1-4. 비로그인도 동작 (로컬에 저장)

**인수 기준**: 첫 부팅 → 메인 진입까지 ≤ 90초.

### F2. 스와이프 (취향 학습)
- F2-1. 카드 한 장 표시 (커버 + 제목 + 메타)
- F2-2. 좋아요/패스 스와이프 또는 버튼
- F2-3. 큐 5개 이하면 자동 prefetch (백그라운드 페이지 로드)
- F2-4. 좋아요/패스 결과는 즉시 로컬 + 큐로 백엔드 push (debounce 3s)

**인수 기준**: 빠르게 10번 swipe해도 카드 끊김 없음.

### F3. 홈 피드
- F3-1. **오늘의 픽** — trending 1위
- F3-2. **트렌딩** — trending 20개 (가로 캐러셀)
- F3-3. **이거 좋아하니까** — 최근 좋아요 1–3개 anchor별 추천 캐러셀 (장르 다양성으로 anchor 선정)
- F3-4. **너 좋아할 만한 거** — top 3 장르 기반 추천
- F3-5. **이번 시즌 신작** — currentSeason
- F3-6. SWR 캐시 — 부팅 즉시 이전 데이터 표시 + 백그라운드 갱신

**인수 기준**: 두 번째 부팅 시 빈 화면 없이 즉시 콘텐츠.

### F4. 탐색 (검색 + 랭킹)
- F4-1. 제목 검색 (한글 입력 → 자동 영어 번역 후 AniList 검색)
- F4-2. 검색 히스토리 6개 보존
- F4-3. 랭킹 정렬: 트렌딩 / 점수 / 인기
- F4-4. 장르 필터 칩
- F4-5. 무한 스크롤 페이지네이션
- F4-6. **헤더 + 리스트 한 덩어리 스크롤**

### F5. 내 목록
- F5-1. 좋아요/패스 탭 분리
- F5-2. 정렬: 최근 / 오래된 / 점수
- F5-3. 인라인 검색 (4개 이상일 때만 노출)
- F5-4. **취향 인사이트 카드** — top 3 장르 + 자주 본 스튜디오 + 평균 점수 (좋아요 5개 이상일 때 노출)
- F5-5. 좋아요 목록 친구에게 공유 (Share 시트)
- F5-6. 개별 항목 삭제

### F6. 디테일 모달
- F6-1. 배너/커버 이미지 + 제목 (한국 출시명 우선)
- F6-2. 장르 칩 + 메타(점수/화수/연도/시즌/스튜디오/상태)
- F6-3. **어디서 봐?** — 라프텔 우선 + AniList 글로벌 링크 (regional 배지)
- F6-4. 줄거리 (한국어 번역)
- F6-5. **시리즈 보는 순서** — Prequel/SideStory/Sequel 등 그룹별
- F6-6. **비슷한 작품** — AniList recommendations 캐러셀
- F6-7. 시리즈/비슷한 작품 카드 탭 → 같은 모달에서 navigate

## 🟡 P1 — 중요

### F7. 인증
- F7-1. 카카오 SSO
- F7-2. 구글 SSO
- F7-3. 이메일/비밀번호 (백엔드 자체 회원)
- F7-4. 로그인 시 로컬 데이터 → 서버 동기화 (`syncLocalToServer`)
- F7-5. 로그아웃 시 로컬 정리 (다음 사용자 보호)

### F8. 백엔드 동기화
- F8-1. 로그인 상태에서 swipes/prefs를 백엔드에 push
- F8-2. 다른 디바이스에서도 같은 데이터
- F8-3. 5분 TTL로 비용 방어
- F8-4. **헤더에 백엔드 헬스 배지** — 동기화 중 / 오프라인 표시

### F9. 장르/취향 재선택
- F9-1. 유저 메뉴에서 장르 다시 고르기
- F9-2. 유저 메뉴에서 취향 다시 분석
- F9-3. 변경 후 홈 피드 즉시 갱신 (`reloadToken`)

## 🟢 P2 — 향후

- F10. 알림 (시즌 신작 알림 등) — expo-notifications 설치만 됐고 미사용
- F11. 시청 기록 / 진행 상황 (1화/2화 등)
- F12. 다국어 (현재 한국어 전용)
- F13. 위젯 (iOS 홈 화면)
- F14. EAS 빌드 (.ipa 1년 유효)

## 비기능 요구사항

| 항목 | 목표 |
|------|------|
| 첫 부팅 → 메인 진입 | ≤ 90초 (온보딩 포함) |
| 두 번째 부팅 → 콘텐츠 | 즉시 (SWR 캐시) |
| 스와이프 응답 | 즉시 (로컬), 백엔드 동기화는 비동기 |
| 디테일 모달 첫 열기 | ≤ 1초 (AniList 응답 기준) |
| 디테일 모달 두 번째 열기 (재부팅 후) | 즉시 (L2 캐시) |
| 비로그인 모드 동작 | 모든 핵심 기능 가능 |
