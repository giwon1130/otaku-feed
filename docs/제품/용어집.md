# 용어집

> **누가 봄**: 모두 (PM, Designer, FE, BE, QA)
> **언제 봄**: 헷갈리는 단어 만났을 때, 새 기능 이름 정할 때
> **단일 진실의 원천**: 이 문서. 코드/UI/문서가 같은 단어를 같은 의미로 써야 함.

## 도메인 용어

| 한국어 | 영어 (코드) | 의미 |
|-------|------------|------|
| 애니 | `Anime` | 한 작품. AniList Media와 1:1 대응. `src/types.ts` |
| 좋아요 | `like` (`SwipeResult`) | 사용자가 보고 싶다 표시 |
| 패스 | `dislike` (`SwipeResult`) | 사용자가 안 보고 싶다 표시 |
| 스킵 | `skip` (`SwipeResult`) | 미사용 (백엔드는 enum에 있음, 클라는 안 씀) |
| 스와이프 기록 | `SwipeRecord` | 한 작품에 대한 좋아요/패스 결과 + 시각 |
| 취향 | `UserPrefs` | 좋아하는 장르 목록 + 온보딩 플래그 |
| 시리즈 | `SeriesEntry` | 같은 작품의 prequel/sequel/외전 |
| 시리즈 관계 | `RelationType` | PARENT/PREQUEL/SEQUEL/SIDE_STORY/SPIN_OFF/ALTERNATIVE/SUMMARY |
| 외부 링크 | `ExternalLink` | 시청 가능한 OTT 플랫폼 |
| 리저널 | `regional` | 한국 전용(라프텔 등) vs 글로벌(Netflix) 구분 플래그 |

## 기능 용어

| 한국어 | 영어 (코드) | 의미 |
|-------|------------|------|
| 오늘의 픽 | `topPick` | 홈 첫 번째 카드 (trending 1위) |
| 트렌딩 | `trending` | AniList TRENDING_DESC 정렬 |
| 이거 좋아하니까 | `becauseLikedSets` | 좋아요한 작품 anchor별 추천 (anchor + recs) |
| 너 좋아할 만한 거 | `forYou` | 추천 장르 기반 인기작 |
| 시즌 신작 | `seasonal` | 현재 시즌의 인기작 |
| 취향 인사이트 | `insight` | MyList의 top 장르/스튜디오/평균 점수 카드 |
| 어디서 봐 | `WhereToWatch` | 디테일 모달의 시청 가능 플랫폼 섹션 |
| 시리즈 보는 순서 | `SeriesOrder` | 디테일 모달의 prequel/sequel 정렬 섹션 |
| 비슷한 작품 | `SimilarList` | 디테일 모달의 recommendations 캐러셀 |
| 줄거리 | `Synopsis` | 디테일 모달의 description 섹션 |

## 온보딩 단계

| 한국어 | 영어 (코드) | 의미 |
|-------|------------|------|
| 로딩 | `loading` (`AppStep`) | 토큰/취향 복원 중 |
| 장르 선택 | `onboarding` | 좋아하는 장르 다중 선택 |
| 취향 분석 | `taste` | 추천 카드 좋아요/패스 |
| 인증 | `auth` | 로그인/회원가입/스킵 |
| 메인 | `main` | 4-탭 메인 화면 |

## 캐싱 용어

| 한국어 | 영어 (코드) | 의미 |
|-------|------------|------|
| SWR | Stale-While-Revalidate | 캐시 즉시 표시 + 백그라운드 갱신 (`api/anilist/swr.ts`) |
| L1 캐시 | 인메모리 LRU | 같은 세션 빠른 재사용 |
| L2 캐시 | AsyncStorage 영구 | 앱 재시작 후에도 유지 |
| 회로 차단 | DeepL circuit breaker | 429 받으면 1시간 호출 안 함 |
| 큐 push | pendingWrites | 스와이프 결과 debounce + bulk 푸시 |
| TTL | Time To Live | 캐시 유효 시간 |

## 데이터 소스

| 한국어 | 위치 | 역할 |
|-------|-----|-----|
| AniList | `graphql.anilist.co` | 글로벌 애니 카탈로그 (메타/추천/관계/링크) |
| 라프텔 | `api.laftel.net` | 한국 OTT — 한국 출시명·시청 가능 여부 |
| DeepL | `api-free.deepl.com` | 영어 → 한국어 번역 (1순위) |
| Google 번역 | `translate.googleapis.com` | 번역 폴백 |
| 백엔드 | `otaku-feed-api` | 인증 + swipes/prefs 동기화 |
