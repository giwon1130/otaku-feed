# 프론트엔드

> **누가 봄**: FE
> **언제 봄**: 새 컴포넌트/탭 만들 때, 코드 패턴 헷갈릴 때
> **함께 봐야 할 문서**: [`아키텍처.md`](아키텍처.md), [`../디자인/컴포넌트.md`](../디자인/컴포넌트.md)

## 빌드 환경

- React Native 0.81 + Expo 54 (dev client, Expo Go 미지원)
- TypeScript 5.9 strict
- Node 22.6+ 권장 (테스트 `--experimental-strip-types`)
- iOS 18.0+ deployment target (Xcode 26 호환)

## 핵심 패턴

### 1. 외부 API 호출 — 항상 wrapper 통해서
- AniList: `import { fetch* } from '../api/anilist'` (절대 fetch 직접 X)
- 백엔드: `import { api* } from '../api/otakuApi'` 또는 `storage.ts`의 `loadSwipes` 등 (UI는 storage.ts 통하는 게 기본)
- 번역: `import { translateAnimeList } from '../api/translate'`

### 2. 에러 처리
```ts
try {
  const data = await fetchTrending(1, 20)
} catch (e) {
  toast.show(e instanceof Error ? e.message : STRINGS.errors.feedFailed, 'error')
  logger.captureException(e, { tab: 'home' })
}
```
사용자엔 toast, 운영엔 logger. 둘 다.

### 3. 로딩 상태
- 화면 전체: `<SkeletonHome />` 등
- 디테일 모달: `<LoadingBar visible={anyLoading} />` (상단 indeterminate)
- 카드 영역: `<Skeleton width=... height=... />`

### 4. 캐시
- AniList 단건 조회: `fetchAnimeById` (L1+L2 자동)
- 트렌딩/시즌: `swr('home:primary', fetchHomePrimary)` 패턴
- 번역: `translateAnimeList` 자동 캐시
- 백엔드 prefs/swipes: `storage.ts`에서 5분 TTL

### 5. render-then-translate
AniList 응답 즉시 영어로 set → translateAnimeList 백그라운드 → swap.
```ts
const raw = await fetchTrending(1, 20)
setTrending(raw)
void translateAnimeList(raw).then(setTrending)
```

### 6. FlatList 가상화
긴 리스트는 항상:
```tsx
<FlatList
  initialNumToRender={12}
  maxToRenderPerBatch={12}
  windowSize={7}
  removeClippedSubviews
/>
```

### 7. ListHeaderComponent
헤더가 fix되면 안 됨 → 리스트와 같이 스크롤되게 `ListHeaderComponent`로.

### 8. keyboardShouldPersistTaps
검색 input 있는 FlatList엔 `"handled"` 추가 — 키보드 떠 있어도 결과 카드 첫 탭에 진입.

### 9. 상태 관리
- React state + AsyncStorage. Redux/Zustand 없음 (앱 규모 작음).
- 캐시는 모듈 변수 (LRU Map 등). 컴포넌트 unmount 시 사라지지 않음.

### 10. 햅틱
모든 버튼은 `hapticLight` 이상. 의미 있는 액션은 `hapticMedium`. 삭제/패스는 `hapticError`.

```tsx
<Pressable onPress={() => { void hapticLight(); onAnimePress(item) }} />
```

### 11. 라우팅
React Navigation 없음. App.tsx의 `step` + `activeTab` 단순 state로 처리. 모달은 prop 전달.

## 공용 훅

| 훅 | 용도 |
|----|------|
| `useToast(durationMs?)` | 토스트 알림 (visible, message, type, show) |
| `useBackendHealth(enabled)` | Railway 헬스 polling (online/offline/unknown) |

## i18n

`src/i18n/strings.ts`의 `STRINGS` 객체. 두 곳 이상 반복되는 사용자 표시 문자열은 여기로.

다국어 도입 시 `ko.ts`/`en.ts` 분리 + `t(key)` 헬퍼 추가.

## 테스트

`npm test` (Node native test runner + `--experimental-strip-types`).
- 순수 함수만 단위 테스트 (mappers, seriesGroup, swr, translate batch)
- 외부 API 호출은 msw로 mock (`client.test.ts` 참고)
- 컴포넌트 테스트는 RN Testing Library 미도입 (필요해지면 추가)

## 안티 패턴

- ❌ `fetch()` 직접 호출 — wrapper 통해
- ❌ `console.log` — `logger.debug` 사용 (production에선 무시됨)
- ❌ 인라인 색상 hex — `C_TOKENS` 참조
- ❌ 중복 카드 JSX — `shared/`로 추출
- ❌ `await` 후 setState 없는 데드 코드
- ❌ `useEffect`에서 cleanup 안 한 setInterval/listener

## 개발 명령어

```bash
npm install
npm run typecheck
npm test

# Metro만 (네이티브 변경 없을 때)
npx expo start --dev-client --port 8082

# 풀빌드 (네이티브 모듈 추가 시)
LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 npx expo run:ios --device "<UDID>" --port 8082
xcrun xctrace list devices   # UDID 확인
```
