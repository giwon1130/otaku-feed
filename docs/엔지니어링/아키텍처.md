## 데이터 흐름

### 핵심 흐름 1: HomeTab 부팅
```
1. swr('home:primary', fetchHomePrimary)  ← AsyncStorage hit이면 즉시 영어
2. cached → setTrending(영어) + setSeasonal(영어)
3. translateAnimeList → setTrending(한국어) swap
4. fresh도 같은 패턴 (백그라운드)
5. forYou + becauseLikedSets는 추가 fetch (병렬)
```

### 핵심 흐름 2: 디테일 모달 진입
```
1. AnimeDetailModal.useEffect 발화
2. 4개 fetch 병렬:
   - fetchAnimeLinks (라프텔 + AniList externalLinks)
   - fetchRecommendations
   - fetchAnimeRelations
   - fetchAnimeById (L1/L2 캐시 → 즉시 가능)
3. fetchLaftelKoreanName (synonyms 한국명 없는 경우 보강)
4. 도착 순서대로 setLinks/setSimilar/setSeries/setEnriched
5. LoadingBar는 anyLoading일 때만 표시
```

### 핵심 흐름 3: 스와이프
```
1. SwipeTab → addSwipe 호출
2. AsyncStorage에 즉시 반영 (UI는 다음 카드로)
3. queuePending → setTimeout 3s
4. 3s 후 flushPending → /swipes/bulk POST
5. AppState 'background' 진입 시 즉시 flush
```

## 외부 의존성

| 서비스 | 용도 | 무료 한도 | 폴백 |
|-------|-----|----------|-----|
| AniList GraphQL | 카탈로그 | 90 req/min/IP | 없음 (앱 핵심) |
| 라프텔 검색 | 한국 OTT | 비공식 (rate limit 모름) | 그냥 안 표시 |
| DeepL | 번역 1순위 | 500k chars/월 | Google 번역 자동 |
| Google 번역 | 번역 폴백 | 비공식 (rate limit 모름) | 원문 영어 |
| 카카오 SSO | 인증 | 무료 | 다른 OAuth |
| 구글 SSO | 인증 | 무료 | 다른 OAuth |

## 핵심 원칙

1. **로컬 우선** — AsyncStorage가 SoT, 서버는 백업/동기화
2. **외부 API 절대 신뢰 X** — AniList도 죽을 수 있음. 항상 try/catch + 캐시 폴백
3. **캐시는 다층** — 인메모리 → AsyncStorage → 네트워크
4. **사용자 액션 즉시 반응** — 백엔드 동기화는 비동기 (큐 + debounce)
